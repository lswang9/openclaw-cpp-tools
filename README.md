# openclaw-cpp-tools

Tools / skills / executors sibling of [openclaw-cpp](https://github.com/lswang9/openclaw-cpp).

**Alignment target:** OpenClaw **2026.10.5** tools & skills surface.

## Status

Placeholder repo. Core currently ships a minimal in-process registry (`echo`, `time_now`) and `POST /tools/invoke`.

This repository will host:

- Expanded built-in tool packs (exec, browser, filesystem policies, …)
- Skills loading
- Sandbox / approval hooks
- Shared tool protocol crates consumed by core + gateway

See [SERIES.md](https://github.com/lswang9/openclaw-cpp/blob/main/SERIES.md) and [PARITY.md](https://github.com/lswang9/openclaw-cpp/blob/main/PARITY.md).
